# 🚗 자율주행 AI 자동차 실습 데이터셋 컬럼 명세서 (Data Dictionary)

본 디렉터리는 《자율주행 AI 자동차 빅데이터 레이크하우스 실무 가이드》 도서의 머신러닝 회귀분석 및 딥러닝 사고 패턴 분류 실습을 위한 공식 데이터셋을 포함하고 있습니다.

---

## 📊 1. 차량 제원 기반 고객 소득 예측 데이터 (`CarMaster2Income.txt`)

* **파일명**: `CarMaster2Income.txt` (훈련 데이터, 약 1,000건) / `CarMaster2Income_Test.txt` (검증 데이터)
* **포맷**: 파이프 구분자(`|`)로 구분된 텍스트 파일
* **목적**: 차량 배기량, 연식, 고객 특성을 기반으로 고객 연소득을 추정하는 OLS 다중 선형 회귀분석 실습

### 📋 컬럼 상세 정의표

| 컬럼명 | 데이터 타입 | 설명 | 예시 값 | 비고 |
| :--- | :---: | :--- | :--- | :--- |
| **`carNum`** | String | 차량 고유 식별 번호 | `A0001`, `A0002` | 기본 키(PK) |
| **`sex`** | String | 차량 소유주 성별 | `남`, `여` | 독립변수 (원-핫 인코딩 대상) |
| **`age`** | Integer | 차량 소유주 연령 (만 나이) | `26`, `34`, `64` | 연속형 독립변수 |
| **`marriage`** | String | 소유주 기혼 여부 | `미혼`, `기혼` | 독립변수 (이진 범주형) |
| **`region`** | String | 소유주 거주 지역 (광역자치단체) | `서울`, `경기`, `전북`, `세종` | 지리 범주형 변수 |
| **`job`** | String | 소유주 직업군 분류 | `회사원`, `전문직`, `자영업`, `공무원`, `주부` | 직무 카테고리 |
| **`capacity`** | Integer | 차량 배기량 (단위: cc) | `2000`, `3000`, `3500`, `4500` | **핵심 독립변수** |
| **`year`** | Integer | 차량 제작 연식 (출고 연도) | `2002`, `2010`, `2015`, `2018` | 연속형 독립변수 |
| **`type`** | String | 차량 세그먼트 등급 코드 | `A` ~ `H` (경형, 중형, 대형, SUV 등) | 등급 범주형 변수 |
| **`income`** | Integer | **소유주 연간 소득 (단위: 만원)** | `3300`, `4400`, `5850` | **🎯 예측 목표 (Target 종속변수)** |

## 🧠 2. 자율주행차 10대 센서 특성 사고 패턴 데이터 (`CarDrivingIncidentInfo.csv`)

* **파일명**: `CarDrivingIncidentInfo.csv` (훈련 데이터, 20만 건 대용량) / `CarDrivingIncidentInfo_Test.csv` (테스트 데이터)
* **포맷**: 쉼표(`,`)로 구분된 CSV 파일 (첫 행은 `총건수, 피처수, 헤더목록` 메타데이터 라인)
* **목적**: 기상, 노면, 차량 주행 센서 신호를 학습하여 사고 발생 시 충돌 부위를 예측하는 3-Class 심층 신경망(DNN) 분류 실습

### 📋 컬럼 상세 정의표

| 컬럼명 | 원문 약칭 | 설명 | 코드값 정의 | 비고 |
| :--- | :---: | :--- | :--- | :--- |
| **`wea`** | Weather | 주행 당시 기상 조건 | `0`: 맑음 (Clear)<br>`1`: 흐림/안개 (Fog)<br>`2`: 비 (Rainy)<br>`3`: 눈/빙판 (Snow) | 외부 환경 센서 |
| **`temp`** | Temperature | 대기 온도 구간 | `0`: 영하 혹한기 (< 0°C)<br>`1`: 상온 쾌적 (0°C ~ 25°C)<br>`2`: 혹서기 (> 25°C) | 환경 센서 |
| **`hum`** | Humidity | 대기 습도 상태 | `0`: 건조 (< 40%)<br>`1`: 보통 (40% ~ 70%)<br>`2`: 다습 (> 70%) | 환경 센서 |
| **`arrCar`** | Around Cars | 주변 차량 밀집도 | `0`: 한산함 (주변 차 거의 없음)<br>`1`: 보통 주행<br>`2`: 혼잡/근접 주행 | V2X / LiDAR 센서 |
| **`timeSlot`** | Time Slot | 주행 시간대 구분 | `0`: 심야/새벽 (00~06시)<br>`1`: 주간 일반 (09~17시)<br>`2`: 출퇴근 피크 (07~09, 18~21시) | 시계열 특성 |
| **`acciArea`** | Accident Area | 도로 선형 및 유형 | `0`: 직선 도로<br>`1`: 급커브/경사로<br>`2`: 교차로/분기점<br>`3`: 고속도로 | 정밀 지도(HD Map) |
| **`drvCond`** | Driver Condition | 운전자 상태 모니터링 (DMS) | `0`: 정상 주행<br>`1`: 주의 분산 (Distracted)<br>`2`: 피로/졸음 주행 (Drowsy) | 운전자 모니터링 센서 |
| **`innCond`** | Inner Condition | 차량 내부 캐빈 환경 | `0`: 정숙함 (Quiet)<br>`1`: 보통<br>`2`: 소음/경고음 발생 | 인포테인먼트/차내 센서 |
| **`carSpd`** | Car Speed | 사고 직전 차량 속도 | `0`: 저속 주행 (< 50 km/h)<br>`1`: 중속 정속 주행 (50 ~ 80 km/h)<br>`2`: 고속/과속 주행 (> 80 km/h) | 차속 센서 (Wheel Speed) |
| **`steeAng`** | Steering Angle | 핸들 조향각 급변 여부 | `0`: 직선 안정 주행<br>`1`: 완만한 차선 변경<br>`2`: 긴급 회피 급조향 (Swerve) | 조향각 센서 (SAS) |
| **`acciPos`** | **Accident Position** | **사고 충돌 부위** | **`0`**: **전방 충돌 (Front)**<br>**`1`**: **측면 충돌 (Side)**<br>**`2`**: **후방 추돌 (Rear)** | **🎯 AI 예측 목표 (Target 레이블)** |

## 📡 3. 카프카 실시간 텔레메트리 스트림 데이터 (`smartcar_logs`)

실시간 파이프라인에서 10대의 자율주행차가 초당 1회씩 카프카를 거쳐 하이브로 쏘아 올리는 패킷 스키마:

```json
{
  "car_id": "CAR-001",
  "speed": 85.5,
  "rpm": 2500,
  "brake_active": false,
  "steering_angle": -3.2,
  "location": "Seoul-Gangnam",
  "latitude": 37.4979,
  "longitude": 127.0276,
  "timestamp": "2026-11-05 13:00:00"
}
```
